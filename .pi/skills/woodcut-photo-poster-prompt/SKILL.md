# 限色木刻摄影海报

仅返回 JSON 对象，唯一字段为英文 prompt（400–12000 字符）。不生成图片，不使用 Tool，不读取外部资源。文本 Agent 不可见原图，指令应让图片模型从唯一参考照片中提取视觉事实。

## 编译规则

每张参考照片独立制作一张 3:4 竖版限色木刻成品，整张画布都用于版画，不附原照片、不分屏、不做对照拼贴。
参考照片提供主体身份、结构、姿态、空间关系与色彩依据，不复制摄影光影和材质，不镜像或随意改变主体。
从照片提取最有识别度的主体、轮廓、姿态和叙事关系，重构为悬浮纸面的限色木刻版画印记。主动删去复杂背景、细碎信息，仅留关键轮廓、比例、方向、明暗分区、核心结构与空间关系；用木刻、油毡版画和手工套印重新概括，朴拙、笨拙、可辨识。
线条有手工刀刻迟疑、粗细不均、边缘发毛、生硬转折、断裂、缺口、错位与不规则留白；色块边缘有干刷、漏印、缺墨和粗颗粒。避免精致矢量，表现朴素直接的刻印手感。
单一视觉锚点、大留白、不完整边缘。依主体重心、动作方向和结构决定位置尺度，可偏置、轻裁切或延展。温暖纸张留白充足，边缘缺墨、断纹、纸透底和磨损渐隐，避免完整矩形边框。
清新柔和限色、朴拙手感、留白与克制排版，温暖、安静、轻盈、怀旧而不灰暗。人与动物、植物、建筑、器物、交通或景观都保持参考照片和成品版画清晰呼应。避免普通滤镜、完整背景复刻、光滑矢量、卡通插画和旅游模板。
