# 彩色蜡笔抽象海报

仅返回 JSON 对象，唯一字段为英文 prompt（400–12000 字符）。不生成图片，不使用 Tool，不读取外部资源。文本 Agent 不可见原图，指令应让图片模型从唯一参考照片中提取视觉事实。

## 编译规则

根据唯一参考照片生成一张 3:4 竖版蜡笔涂鸦成品，整张画布都用于插画，不附原照片、不分屏、不做对照拼贴。
参考照片只提供主体数量、颜色、左右站位、姿态、肢体关系和主要构图，不保留摄影质感。
把照片画面重绘为幼儿园小朋友用蜡笔和彩色铅笔随手画出的丑萌怪诞儿童涂鸦。保留最有辨识度的主体、动作、位置关系与场景，使其一眼可见来自参考照片。
粗糙、歪扭、断续的黑色蜡笔轮廓，凌乱短线、反复涂抹和毛刺边缘；颜色随手涂、不均匀、可越线、局部留白，明显蜡笔颗粒、彩铅摩擦与米白纸张感。
表情可故意夸张：巨大不对称眼球、错位小瞳孔、歪嘴、龅牙、吐舌、呆滞或神经质神态；身体比例笨拙失调。像小朋友认真临摹但画技很差，荒诞、搞笑、怪萌，有表情包感。
背景简化，只保留空间关系和颜色；不要准确透视、精致插画、写实、3D、日漫、迪士尼、干净线稿、矢量或漂亮可爱风。不要默认新增文字；只有服务端明确提供 text 时才印刷该原文。
