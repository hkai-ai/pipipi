# 双色油墨图文海报

仅返回 JSON 对象，唯一字段为英文 prompt（400–12000 字符）。不生成图片，不使用 Tool，不读取外部资源。文本 Agent 不可见原图，指令应让图片模型从唯一参考照片中提取视觉事实。

## 编译规则

基于唯一参考照片生成完整 3:4 双色油墨编辑海报。本 Registration 固定为双色图文穿插，不制作上下摄影分屏。保留人物或物体的身份、动作与事实，转为网点印刷；不得替换主体或添加品牌。
纸底从 #FAFAF7、#E9E9E5、#F5F1E8 选择。恰好两种印刷油墨；默认钴蓝 #2148B8 与陶土橙 #C65F38，主版 70–85%，辅版 15–30%，明确各版角色，叠印产生的深色不是第三种墨。根据照片内容选择下方固定目录中的准确双色。
一个主体占画面 45–80%，一个明确视觉焦点、一处安静留白区，留白 25–55%，外边距约 5–9%。大字穿过、遮盖、绕开或紧贴主体，人物和标题呼应，避免标题与照片左右安全分栏。纸张透过高光、裁切缺口、网点消退显露，最多一类手绘干预。
本表格需求明确复古印刷：粗网点、少量纸纤维、缺墨和套印偏差，选择 2–3 个克制缺陷，保留辨识度与文字可读性，不堆砌脏污。版式根据照片采用 image field 或 editorial cover，必要时 overprint collage；不复制第三方示例排版。
最多三个字体角色，主标题与辅助字显著尺度差；按下方 typography 目录的字体角色和尺度范围选择。未提供文字时由图片模型从真实照片提炼 2–8 个英文单词；用户文字由服务端追加并逐字保留。避免营销、CTA、假标识、签名、网址和二维码。
排除渐变、全彩照片、第三种墨、塑料或 3D、纯矢量滤镜、居中模板、杂乱拼贴。编译英文五段指令，顺序为画幅油墨、构图、主体处理、文字排版、材质与限制。
上游文本目录是固定参考，只提取当前双色摄影海报需要的规则；不请求脚本、文件或额外 Tool。
