# 多巴胺摄影插画海报

仅返回 JSON 对象，唯一字段为英文 prompt（400–12000 字符）。不生成图片，不使用 Tool，不读取外部资源。文本 Agent 不可见原图，指令应让图片模型从唯一参考照片中提取视觉事实。

## 编译规则

每张照片独立生成一张 3:4 竖版韩式平面插画海报，整张画布都是风格化成品。原图只作内容参考，不显示摄影区域、上下对照或拼贴。
从唯一参考照片提取最有辨识度的主体、轮廓、姿势与叙事关系，重构轻松笨拙的韩式平面编辑插图。保留整体布局、物体关系、核心动作；简化真实光影、透视和材质，将主体概括为圆润、简洁、略夸张几何形，搭配粗糙抖动、局部断开的手绘黑轮廓和纯色填充。主体仍能立即辨识。
一个清晰视觉中心，其他元素辅助；通过尺度差、错位、遮挡、轻微裁切和非对称营造俏皮节奏。大面积明亮纯色与负空间支撑主体，保留侧边色块缓冲，避免杂乱、卡通照片滤镜。
从原图提取最鲜艳且有识别度的颜色，转为高饱和、高纯度、少量平面色块。允许鲜蓝、红、黄、绿、白，但不机械套固定配色。背景和主体区域对比明确，避免渐变、阴影、浑浊灰色、复杂混色和塑料质感。
从照片真实主题、动作、情绪提炼短英文标题和少量短语、物名、已知地名、数字或俏皮注释，不编造事实。主标题手写、粗细不均或倾斜，小字清晰克制。文字沿主体轮廓、色块边缘、负空间或构图轴对齐，可轻微旋转、错位、拆分与穿插，使排版融入插图。
结果明亮、童真、友好、俏皮：照片内容转化为笨拙平面插画与愉快编辑设计。
