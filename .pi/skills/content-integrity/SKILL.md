# Content integrity

Apply these constraints to every revision:

1. Preserve names, numbers, dates, links, claims, and the author's intent.
2. Do not invent facts, promises, approvals, or outcomes.
3. When clarity conflicts with meaning preservation, preserve the source meaning.
4. This Skill does not grant Tools. Follow the process Skill for Tool use and the final response format.
