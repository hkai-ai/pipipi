# 摄影抽象记忆海报

仅返回 JSON 对象，唯一字段为英文 prompt（400–12000 字符）。不生成图片，不使用 Tool，不读取外部资源。文本 Agent 不可见原图，指令应让图片模型从唯一参考照片中提取视觉事实。

## 编译规则

只编译一张 3:4 竖版、无文字的独立抽象作品。唯一参考照片只提供内容线索，不生成摄影区域、不做上下分屏或对照拼贴，服务端不会附加原照片。
执行解构、提炼、重构。图片模型先观察主质量块、轴线、边界、数量、间隔、方向、遮挡、深度、色彩角色、非对称和重要空隙。选择一个主元素、至多两个辅助关系，每个最终符号都必须能对应一个可见来源事实。
删除摄影表面、细节、次要物件与写实轮廓，保留相对主次、左右上下次序、方向流动、数量组、间隙、聚集、遮挡和深度关系；允许有依据的位移、压缩、拆分、重叠和整体缩放。重构新的非具象构成，不临摹微缩场景、风格转换、照片滤镜、矢量化或通用图标。
用一个主符号家族和至多两个辅家族：平面有机色块、细线、点、短条、弧线、少量轮廓。主图案作为整体占整张画布宽 30–42%、高不超过 28%，空白 75–88%，靠下中部或有依据的非对称位置。保留内部尺度与间隔，不把符号散满画面。
背景为完全均一、中性象牙色 #F3F0E8，中央、边缘、四角和未来文字区连成一体。禁止渐变、光照衰减、阴影、暗角、条带、接缝、纸纹、颗粒、污渍、雾或水彩晕染。只在源自照片的抽象符号内使用颜色。
从照片提取 3–5 个有事实对应的色彩角色，保留明度、饱和度和主次；真实存在时可用 2–3 个克制强调色。单色来源维持克制，不能为装饰增加颜色、内容、对称、遮挡后的身体或建筑。
生成图必须无任何文字、数字、水印、标题或色卡。档案编号、真实日期、用户提供的英文短语由服务端在抽象成品上绘制。本适配不使用上游参考图片、Python 脚本、跨请求序号记忆或自动重绘。
