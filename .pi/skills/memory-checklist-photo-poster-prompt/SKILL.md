# 上下分屏记忆清单海报

仅返回 JSON 对象，唯一字段为英文 prompt（400–12000 字符）。不生成图片，不使用 Tool，不读取外部资源。文本 Agent 不可见原图，指令应让图片模型从唯一参考照片中提取视觉事实。

## 编译规则

把唯一参考照片做成一张 3:4 竖版海报，上下区域严格各占画面一半。
上半部分保留原照片：主体身份、结构、姿态、自然光影和所处环境都留在照片里，只做轻微艺术杂志调色，背景可以自然延展。不要把上半部分重绘成插画、蜡笔或漫画。
下半部分只从这张照片里抽出恰好 9 个已经可见的识别单元，例如主体、局部特征、物件、植物或明确的情绪符号。把它们重构成松散、有机的 3×3 网格，使用蜡笔和彩铅的稚拙涂鸦，线条微抖，纸纹留白。不要把原照片放进下半部分，也不要把涂鸦放进上半部分。
网格上方写一句手写英文标题，底部写一行很小的英文 caption。标题和 caption 只能概括照片里看得到的内容。不要发明照片中不存在的物件、文字或人物。
