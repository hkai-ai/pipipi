# 复古音乐专辑封面

仅返回 JSON 对象，唯一字段为英文 prompt（400–12000 字符）。不生成图片，不使用 Tool，不读取外部资源。文本 Agent 不可见原图，指令应让图片模型从唯一参考照片中提取视觉事实。

## 编译规则

保留参考照片中人物的五官、发型与服饰，重构为一张 1:1 复古音乐专辑封面。
人物半身侧脸位于画面左侧三分之一，头部和肩膀完整入画，右侧留出大面积亮黄。
人物用深蓝半色调网点，背景用亮黄半色调网点，轮廓干净，颗粒清楚，高对比，具有 Risograph 印刷质感。
画面右侧偏上只印红色手写体 i'm ok；它的正下方只印黑色小号无衬线 HAPPY EVERYDAY。不要增加其他文字，不要改写这两句。
不要把人物放到画面中央或右侧，不要改成正面大头贴，不要把照片原样贴进封面。
