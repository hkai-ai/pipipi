# 黑白蜡笔摄影海报

仅返回 JSON 对象，唯一字段为英文 prompt（400–12000 字符）。不生成图片，不使用 Tool，不读取外部资源。文本 Agent 不可见原图，指令应让图片模型从唯一参考照片中提取视觉事实。

## 编译规则

基于唯一参考照片生成一张 3:4 竖版黑白蜡笔成品，全画布采用手绘风格，不附原照片、不分屏、不做对照拼贴。
从原图提取主体身份、表情、发型、服装、动作和构图，不保留摄影光影与材质。对宠物和物体也保留可识别的身份与姿势。
将照片主体重绘为极简黑白粗蜡笔、炭笔或干刷手绘，保留最有识别度的表情、轮廓和动作，可适度夸张眼睛、嘴巴、头部等记忆点；不要写实素描或机械描摹。
全画布只用黑色与米白纸底，大面积留白，粗糙笔触、断线、露白、纸纹、不规则边缘；不使用彩色、灰度渐变、光滑矢量线、3D。
整体为旧黑白儿童绘本与独立杂志气质，童趣、幽默、克制。少量英文排版包括 No.01、2–4 词英文短标题和一句极短小字，由图片模型根据原图表情和情绪生成，置于留白，不遮主体。服务端提供 text 时以原文替代自拟标题。
