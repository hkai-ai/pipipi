# Triage Labels

工程 Skill 使用以下 canonical role 与 GitHub label 映射：

| Canonical role | GitHub label | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可由 Agent 执行 |
| `ready-for-human` | `ready-for-human` | 需要人工实现或判断 |
| `wontfix` | `wontfix` | 不计划处理 |

Skill 提到 canonical role 时，使用同一行的 GitHub label。若仓库以后采用不同命名，只修改右侧映射，不改 Skill 语义。
